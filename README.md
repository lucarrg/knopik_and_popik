# кнопик & попик

Frontend-прототип личного кулинарного сайта «кнопик & попик».

## Как открыть

Откройте `index.html` в браузере. Стили и скрипт подключаются локально из папок `css/` и `js/`.

Backend отсутствует. Сейчас проект находится на этапе разработки визуального интерфейса.
